# Contributing / Đóng góp

Contribute original source code, documentation, or **small, rights-cleared** review examples only. Do not upload original or modified game archives, complete EN/VI dictionaries, commercial font files, extracted third-party language packs, executable modifications, private HAR exports, credentials or unpublished game story text.

Each proposed correction should identify an exact local entry ID, the intended meaning, applicable character/speaker context and how special tokens/newlines are preserved. Copyrighted game dialogue should not be pasted in bulk into public issues or pull requests.

Run `python -m unittest discover -s tests -v` before submitting. Never run game executables or inject modified DLLs as part of these tests. Keep separate local backups; no tool in this repository installs anything into a game directory.

## Tiếng Việt

Chỉ chia sẻ mã nguồn tự viết và tài liệu được phép phát hành. Không công khai bộ game, dữ liệu dịch trọn bộ, phông thương mại hoặc thông tin đăng nhập. Mọi chỉnh sửa phải có bằng chứng ngữ nghĩa và giữ nguyên placeholder / xuống dòng.
